1. デザインの方向性

  • 地域に根ざした、親しみやすく穏やかな医療機関の印象にする。
  • 白・オフホワイトを基調に、青みのある緑を主要色として使う。
  • 葉の写真・イラストを見出しやナビゲーションのアクセントに使う。
  • 施設やスタッフの写真を大きく見せ、飾りより情報の読みやすさを優先する。
  • 角丸や柔らかな背景色を使い、強い影や高彩度色を多用しない。

3. 文字

  • 基本書体は Google Fonts の Zen Maru Gothic。代替書体は Noto Sans JP、Yu Gothic、Meiryo、sans-serif の順。
  • 本文は 16px、行送り 1.75、字間 .015em。
  • リード文は 18px、行送り 1.8〜1.9。
  • セクション見出しは 24px、下層ページの項目見出しは 20px、小見出しは 18〜20px。
  • ボタン文字は 17px、太さ 600。
  • ヒーローのキャッチコピーはデスクトップ 64px。画面幅に応じて縮小する。
  • 情報の階層は文字サイズだけでなく、余白と背景色でも示す。

4. レイアウトと余白

  • デスクトップの共通コンテンツ幅は最大 1240px。トップページの左右余白は基本 100px。
  • 下層ページ本文は最大 1200px、左右 24px 以上の余白を確保する。
  • トップページのセクション見出し帯は高さ 50px。本文は上に 58〜60px の余白を置く。
  • 下層ページの本文上部は 58px、セクション間はおよそ 42px。
  • 段落は内容のまとまりごとに分け、関連情報を同じ列やカードにまとめる。

レスポンシブ

  • 1000px 以下では左右余白を 32px 前後に縮める。
  • 768px 以下では本文の左右余白を 24px 前後にする。
  • 480px 以下では左右余白を 8〜12px 程度にし、2列表示を必要に応じて1列にする。
  • ページ全体に横スクロールを出さない。横幅が必要な表は、表のコンテナ内でスクロールさせる。
  • 小さい画面でも本文文字は原則 16px 以上にする。

5. 共通コンポーネント

ヘッダーとナビゲーション

  • トップページは施設写真を背景に、キャッチコピー、診療時間、ロゴを配置する。
  • キャッチコピーは黄色の太字とし、葉の枝のモチーフを添える。
  • メインナビはメイン緑の帯に白文字、選択中項目は黄色で示す。
  • 下層ページはページごとのヒーロー画像、パンくず帯、本文の順にする。
  • モバイルのナビゲーションはトグルで開閉できる形にする。

見出し

  • トップページの大見出しはサブカラーの帯に白文字と葉の画像を並べる。
  • 下層ページの項目見出しは淡い緑の帯に本文色の文字と小さな葉アイコンを置く。
  • 装飾用の葉画像は空の alt を使う。

ボタンとリンク

  • 主ボタンはメイン緑のピル形（border-radius: 999px）、白文字。標準 17px、最小高さ 44px。
  • ホバー時は少し濃い緑へ変化させる。
  • 画像リンクにも、用途が分かる代替テキストまたはアクセシブルな名前を付ける。
  • 新しいタブで開く外部リンクには rel="noopener noreferrer" を付ける。

カード・画像・情報一覧

  • 診療内容カードは白背景と大きめの角丸を基本とし、画像と本文の対応を明確にする。
  • 人物写真は統一した比率・トリミングを使う。画像は max-width: 100% を基本とする。
  • 診療時間表は曜日と時間帯の対応を明確にし、罫線とセル余白を設ける。
  • 休診表示は色に加えて「休」などの文字も使う。
  • お知らせはタイトル・日付・分類が見分けられる一覧にする。FAQ は質問と回答の対応、開閉状態を明確にする。

フッター

  • メイン緑の背景に白文字を使う。
  • ロゴ、連絡先、架空サイトである旨、著作権表記を整理して掲載する。
  • 予約ページを含む全ページで共通フッターとページトップボタンを使う。

予約フォーム

  • 予約ページは共通ナビゲーション、パンくず、フッターを他ページと揃える。フォーム本文は最大 1200px 幅にする。
  • ページ見出しと案内は淡い緑のパネルにまとめ、「入力・確認・完了」の3段階を表示する。現在の段階はメイン緑と白文字で示す。
  • 予約前の注意事項は淡い背景色とサブカラーの左罫線で区別する。
  • 入力項目は白いカードにまとめ、細い罫線と 18px の角丸を使う。項目見出しは淡い緑の帯に葉アイコンを添える。
  • 広い画面では2列、768px 以下では1列にする。入力欄は高さ約 50px、角丸 10px を基準にする。
  • 必須は赤、任意は淡いグレーのバッジで表示する。入力エラーは赤い文字と枠、フォーカスは黄色の 3px アウトラインで示す。
  • 確認画面では項目名と値を表形式で見せ、完了画面では受付状態と次の案内を示す。
  • 予約操作ボタンはメイン緑のピル形、最小高さ 52px、標準最小幅 280px とする。
  • 現在のフォームは教材用サンプルで、実際の送信・予約登録を行わないことを画面に明記する。

6. 動きとアクセシビリティ

  • 動きは葉の演出など短く補助的な用途に限る。
  • prefers-reduced-motion: reduce の場合は装飾アニメーションを止める。
  • 操作要素はキーボードで使えるようにし、フォーカス位置を見える状態にする。
  • 色だけで状態を区別せず、文字や記号も併用する。
  • 内容を伝える画像には適切な代替テキストを付け、装飾画像は空の alt を使う。
  • リンク・ボタンには用途が分かる名前を付ける。

7. 画像・ブランド素材

  • 既存のロゴ、葉素材、施設写真、スタッフ写真を優先して再利用する。
  • 追加素材は既存の色味、写真の明るさ、自然な雰囲気に合わせる。
  • ロゴや葉の色・形を変更する場合は全ページで一貫させる。
  • 地図のクリック先や住所などのデータは、画面表示とリンク先を個別に確認する。

8. 実装上の注意

  • 共通見た目は assets/css/style.css に追加し、ページ固有スタイルはページクラス配下に限定する。
  • 既存の CSS 変数とコンポーネントを優先し、同じ見た目の別実装を増やさない。
  • ブレークポイントは既存の 1200px、1000px、768px、480px を基本にする。
  • 各ページのヘッダー、パンくず、フッター、見出し、本文幅を揃える。
  • 予約ページ固有のスタイルは assets/css/reservation.css に置き、共通ナビゲーション・パンくず・フッターのスタイルを再利用する。
  • 所在地・診療時間・連絡先を変更するときは、関連ページ間の整合性を確認する。
