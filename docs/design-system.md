# 佐藤医院 Webサイト デザインルール

本書は、現時点のサイト実装（`assets/css/style.css` と各 HTML ページ）から整理したデザインルールです。新しいページやコンポーネントを追加するときは、既存の共通パターンを優先してください。CSS の実値はサイトの実装を基準にしています。

## 1. デザインの方向性

- 地域に根ざした、親しみやすく穏やかな医療機関の印象にする。
- 白・オフホワイトを基調に、青みのある緑を主要色として使う。
- 葉の写真・イラストを見出しやナビゲーションのアクセントに使う。
- 施設やスタッフの写真を大きく見せ、飾りより情報の読みやすさを優先する。
- 角丸や柔らかな背景色を使う。強い影や高彩度色を多用しない。

## 2. 色

| 役割 | CSS 変数 | 値 | 用途 |
|---|---|---|---|
| メイン | `--main` | `#2E8B7F` | ナビゲーション、ボタン、フッター |
| サブ | `--sub` | `#6A9199` | セクション見出し、パンくず |
| 淡い緑 | `--lightgreen` | `#DCEDEA` | FAQ・診療内容などの小見出し |
| ベージュ | `--beige` | `#EDE4D6` | セクション背景の変化 |
| ベース | `--base` | `#F8FAF8` | ページ背景 |
| 本文 | `--text` | `#263B3A` | 基本文字 |
| 白 | `--white` | `#FFFFFF` | カード、反転文字 |
| ヒーロー強調 | `--hero` | `#FFD700` | ファーストビューのキャッチコピー、選択中ナビ |
| 休診・注意 | `--holiday` | `#DC143C` | 休診表示 |
| 葉の黄緑 | `--green` | `#C5DF93` | 診療表などの補助的な強調 |
| 罫線 | `--line` | `#DCE6E3` | 表・区切り線 |

新しい色が必要な場合は、まず既存変数で表現できるか確認し、色を追加するときは用途を限定してください。

## 3. 文字

- 基本書体は Google Fonts の `Zen Maru Gothic`。読み込みに失敗した場合は `Noto Sans JP`、`Yu Gothic`、`Meiryo`、sans-serif の順で代替する。
- 本文の基本サイズは `16px`、行送りは `1.75`、字間は `.015em`。
- リード文は `18px`、行送り `1.8〜1.9` を目安にする。
- セクション見出しは `24px`、下層ページのグループ見出しは `20px`。小見出しは `18〜20px` を基準にする。
- ボタン文字は `17px`、太さ `600`。
- ヒーローのキャッチコピーはデスクトップ `64px`、タブレットでは縮小し、狭い画面では `26px` 前後を基準にする。
- 見出し以外で本文を太字・大サイズにしすぎず、情報の階層は余白と背景色でも示す。

## 4. レイアウトと余白

- デスクトップの共通コンテンツ幅は最大 `1240px`。メインページの左右余白は基本 `100px`。
- 下層ページ本文は最大 `1200px`、左右 `24px` 以上の余白を確保する。
- メインページのセクション見出し帯は高さ `50px`。本文領域は上におよそ `58〜60px` の余白を置く。
- 下層ページの本文上部は `58px`、セクション間はおよそ `42px` を基準にする。
- 本文やカード内の段落は、内容のまとまりごとに分け、詰め込みすぎない。
- 関連情報は同じ列・カードにまとめ、ナビゲーションから本文への流れを明確にする。

### レスポンシブ

- `1000px` 以下では左右余白を `32px` 前後に縮める。
- `768px` 以下では本文の左右余白を `24px` 前後にし、2列レイアウトは内容に応じて1〜2列へ切り替える。
- `480px` 以下では左右余白を `8〜12px` 程度にし、アクセス情報などの2列表示を1列にする。
- 画面幅に合わせて画像を縮小し、ページ全体に横スクロールを発生させない。表のように横幅が必要な要素は、その要素のコンテナ内でスクロールさせる。
- 小さい画面でも本文文字を `16px` 未満にしないことを基本とする。

## 5. 共通コンポーネント

### ヘッダーとナビゲーション

- トップページのファーストビューは施設写真を背景にし、その上にキャッチコピー、診療時間、ロゴを配置する。
- キャッチコピーは黄色、太字。葉の枝のモチーフを添える。
- メインナビゲーションはメイン緑の帯に白文字で表示し、選択中項目は黄色で示す。
- 下層ページはページごとのヒーロー画像、サブカラーのパンくず帯、本文の順にする。
- モバイルのナビゲーションはトグルで開閉できる形にする。

### 見出し

- トップページの大見出しはサブカラーの帯に白文字と葉の画像を並べる。
- 下層ページの項目見出しは淡い緑の帯に本文色の文字と小さな葉アイコンを置く。
- 葉画像は装飾として扱い、意味を担う場合を除き代替テキストは空にする。

### ボタンとリンク

- 主ボタンはメイン緑のピル形（`border-radius: 999px`）、白文字。標準文字サイズ `17px`、最小高さ `44px`。
- ホバー時は少し濃い緑へ変化させる。
- 画像全体をリンクにする場合も、リンクであることが分かる代替テキストまたはアクセシブルな名前を付ける。
- 外部サイトを新しいタブで開くリンクには `rel="noopener noreferrer"` を付ける。

### カード・画像

- サービスカードは白背景と大きめの角丸を基本とし、画像と本文の対応を明確にする。
- 人物写真は統一した比率・トリミングを使う。
- 画像は原則 `max-width: 100%` とし、表示枠に合わせる場合は `object-fit: cover` を使う。
- 写真の角丸はカードの一部として使う。すべての画像を装飾的に丸くしない。

### 表と情報一覧

- 診療時間などの表は曜日・時間帯の対応を明確にし、罫線とセル余白を設ける。
- 休診は `--holiday` で示し、記号だけに頼らず「休」などの文字も併用する。
- お知らせはタイトル・日付・分類が見分けられる一覧形式にする。
- FAQ は質問と回答の視覚的な対応を明確にし、開閉ボタンの状態を支援技術にも伝える。

### フッター

- メイン緑の背景に白文字を使う。
- ロゴ、連絡先、架空サイトである旨、著作権表記を整理して掲載する。

## 6. 動きとアクセシビリティ

- 動きはナビゲーションやヒーローの葉の演出など、短く補助的な用途に限る。
- `prefers-reduced-motion: reduce` が有効な場合は、装飾アニメーションを止める。
- すべての操作要素をキーボードで操作できるようにし、フォーカス位置を見える状態にする。
- 色だけで状態を区別せず、文字や記号も併用する。
- 内容を伝える画像には内容に合った代替テキストを付け、装飾画像は空の `alt` を使う。
- リンク・ボタンには用途が分かる名前を付ける。

## 7. 画像・ブランド素材

- 既存のロゴ、葉素材、施設写真、スタッフ写真を優先して再利用する。
- 素材を追加する場合は既存の色味・写真の明るさ・自然な雰囲気に合わせる。
- ロゴや葉の色・形を変更する場合は、全ページで一貫させる。
- 地図画像のクリック先や住所などの実データは、ページに見える表示とリンク先を混同せず、個別に確認する。

## 8. 実装上の注意

- 共通見た目は `assets/css/style.css` に追加し、ページ固有スタイルは既存のページクラス配下に限定する。
- 既存の CSS 変数とコンポーネントを優先し、同じ見た目の別実装を増やさない。
- ブレークポイントは既存の `1200px`、`1000px`、`768px`、`480px` を基本にする。
- 各ページのヘッダー、パンくず、フッター、見出し、本文幅のパターンを揃える。
- 実データの更新はデザイン調整と分けて扱い、所在地・診療時間・連絡先を変更するときは関連ページ間の整合性を確認する。
